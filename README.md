
# auto_command_downloader

Скрипт для Bash, который перехватывает ненайденные команды
и предлагает установить пакет через pacman.

## Установка

1. Скопируйте файл в домашнюю папку:
   cp .bash_command_not_found ~/

2. Установите pkgfile:
   sudo pacman -S pkgfile
   sudo pkgfile --update

3. Добавьте в ~/.bashrc:
   source ~/.bash_command_not_found

## Использование

Введите несуществующую команду, например htop.
Скрипт предложит установить соответствующий пакет.
