# auto_command_downloader

Скрипт для Bash, который перехватывает ненайденные команды
и предлагает установить нужный пакет через pacman.

Привет, пользователь! Ты наверняка сталкивался с ситуацией,
когда вводишь команду, а терминал отвечает «command not found».
Этот скрипт решает проблему: он ищет, в каком пакете лежит команда,
и предлагает её установить.

## Установка

1. Скопируйте файл в домашнюю папку:

   cp .bash_command_not_found ~/

2. Установите pkgfile и обновите базу:

    sudo pacman -S pkgfile
    sudo pkgfile --update

3. Добавьте строку в ~/.bashrc:

    source ~/.bash_command_not_found

4. Перезапустите терминал или выполните:

    source ~/.bashrc

Использование

Введите несуществующую команду, например:
bash

$ firefox

Скрипт ответит:

Команда 'firefox' не найдена. Она есть в пакете: firefox
Установить? [y/N]
